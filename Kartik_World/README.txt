KARTIK.WORLD — WEBSITE PACKAGE

Folders:
- home/       Main website page
- dashboard/  Personal dashboard
- games/      Games hub and three separate 3D games

Games:
- games/fighting-arena/ — 3D combat survival
- games/neon-rush/      — 3D endless racing
- games/snake-x/        — 3D snake arcade

Run with VS Code Live Server starting from home/index.html. Navigate to Dashboard > Games.
Read SETUP.txt files in the root and each folder for instructions.
The 3D games load Three.js from a CDN and need internet access plus WebGL support.
The leaderboard currently stores local personal bests in the browser. A shared global leaderboard needs a backend/database.
